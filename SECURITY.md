# Security policy

## Reporting a vulnerability

Please avoid posting potential exploits, credentials, API keys, OAuth callback URLs, or personal information in a public issue.

If a security concern affects this portfolio code, use GitHub's **Report a vulnerability** / private security advisory feature when available. Otherwise, contact the repository owner privately through their GitHub profile before sharing sensitive details.

## Supported versions

The current `main` branch of this portfolio snapshot is the supported code reference. No hosted public service is provided.

## Scope

This is a sanitized portfolio repository and is not the source of truth for any live private deployment. Do not assume the existence of accessible public infrastructure.
